Diaporama de singe

Serveur MCP privé de la version ChatGPT. Le dépôt Codex est un projet entièrement distinct.

Connexion à ChatGPT

Dans les paramètres de ChatGPT, crée une connexion MCP personnalisée et indique l'adresse suivante :

https://diaporama-de-singe-chatgpt.netlify.app/mcp

Choisis l'authentification OAuth ; ChatGPT peut enregistrer son client automatiquement. Sur la page de consentement, saisis ton code d'accès personnel au projet. Ce code ne doit jamais être transmis dans une conversation ou ajouté à l'URL du serveur.

Fonctions principales

  • Créer plusieurs diapositives HTML/CSS en une seule opération.
  • Modifier des éléments, des styles, du texte, des notes et des animations, sans réécrire toute une présentation.
  • Effectuer des modifications en lot avec contrôle des conflits.
  • Gérer les dossiers, les images référencées et les variantes graphiques.
  • Obtenir des liens d'export HTML/JSON à durée limitée, ou préparer un export PowerPoint dans l'éditeur Web.

Limites actuelles

La conversion PPTX fidèle ou éditable s'effectue dans l'application Web ; elle n'est pas encore exécutée entièrement sur le serveur MCP. L'intégration directe Google Slides, la recherche d'images via MCP et le moteur d'animations au clic feront l'objet d'étapes distinctes.
